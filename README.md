# Learn German

Vocabulary tables built from German podcasts: German → English → Farsi (فارسی),
with a memory code (Merk-Code) for every word and colour-coded genders
(der = blue, die = red, das = green, verbs = purple).

| Folder | Source | Files |
|---|---|---|
| `altermagnete/` | Spektrum-Podcast – *Altermagnete: Eine neue Form des Magnetismus* (6 Nov 2026), intro | `altermagnete_vocab.tex`, `altermagnete_vocab.pdf` |

Build: `xelatex altermagnete_vocab.tex` (run twice). Needs the DejaVu fonts.
