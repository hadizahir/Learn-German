# Learn German

Vocabulary tables built from German podcasts: German → English → Farsi (فارسی),
with pronunciation (IPA + easy spelling), a memory code (Merk-Code) for every word, colour-coded genders
(der = blue, die = red, das = green, verbs = purple), and a step-by-step grammar section (simple → complex).

| `altermagnete/` | same episode, Teil 2 | `altermagnete_teil2_vocab.tex`, `altermagnete_teil2_vocab.pdf` |
